# Política de segurança

Não publique vulnerabilidades, credenciais ou dados reais de clientes em issues.
Relate problemas de segurança de forma privada pelo canal indicado no perfil do
mantenedor no GitHub. Antes da divulgação pública, use o formulário privado de
security advisory do repositório.

Este projeto usa apenas dados fictícios. Arquivos locais de configuração e
segredos são ignorados pelo Git. Consulte `docs/ia/POLITICA_DE_USO.md` antes de
enviar código, logs ou configuração a uma ferramenta de IA.

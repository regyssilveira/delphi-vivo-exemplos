# Como contribuir

1. Abra uma issue descrevendo problema, versão do Delphi e plataforma.
2. Crie uma branch curta a partir de `main`.
3. Preserve as convenções em `docs/CONVENCOES.md`.
4. Execute `build/validate.ps1` antes do pull request.
5. Não inclua componentes comerciais, binários, credenciais ou dados reais.

Contribuições enviadas intencionalmente são licenciadas sob Apache License 2.0,
conforme a cláusula 5 da licença.
